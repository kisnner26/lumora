# seguridad

el puente de lumora escucha solo en `127.0.0.1` (nunca en la red) y no envía datos tuyos a ningún servidor propio. las conexiones salientes son las de las fuentes que lumora consulta: letras (lrclib), metadatos (iTunes, Wikipedia, Deezer), fuentes de Google Fonts y, si lo activas, Claude.

si encuentras una vulnerabilidad, no abras un issue público: escríbeme por [GitHub](https://github.com/kisnner26) con el detalle y cómo reproducirla.
